# 内部工单台 · 需求与验收

## 范围

本地内部 IT 工单台：创建工单、查看列表、状态切换（待处理 / 处理中 / 已完成）、删除工单，刷新后通过 localStorage 持久化；包含空态提示与状态计数 / 筛选。

## 验收标准

- 能打开主页，不是空白页或 404。
- 能创建至少 1 条工单，并立刻出现在列表顶部，默认状态为「待处理」。
- 能将工单状态切换为「处理中」和「已完成」，界面可区分状态。
- 能删除工单，删除后不再出现在列表中。
- 刷新页面后数据仍在（localStorage 即可）。
- 无登录、无外部付费 API、无云端账号体系。
- 交付说明写清如何本地打开（直接打开 index.html 或一条启动命令）。

## UI 规范

- 复用 `shell.css` + `shell.js` + `theme.css`（深蓝侧栏 + 白顶栏；内容区深蓝 #1B4F9C + 青绿 #0D9488）。
- 首页内容区保留功能入口卡片（标题 / 标签 / 说明）。
- 子页与入口共用同一套壳；表单 / 列表可操作。
- 入口同时挂到 `index.html` 门户卡片与 `shell.js` 的 `window.MAWP_NAV`。
- 状态样式区分：待处理普通（蓝）、处理中高亮（黄）、已完成弱化（灰）。
