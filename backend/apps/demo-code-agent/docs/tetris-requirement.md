## 1. 需求概述（Summary）

实现一个可直接在浏览器游玩的俄罗斯方块（Tetris）游戏：用户打开 `index.html` 即可开始游戏，无需安装依赖、无需构建步骤、不依赖外部 CDN。核心玩法包括 10×20 棋盘、方块自动下落、左右移动、旋转、软降/硬降、满行消除计分、下一个方块预览、键盘控制、暂停/继续、游戏结束与一键重开。

---

## 2. 目标（Goals）

- **G1**：浏览器打开 `index.html` 后可直接开始游戏。
- **G2**：提供完整可玩的俄罗斯方块核心循环：下落 → 移动/旋转 → 落底固定 → 消行计分 → 生成新块。
- **G3**：展示当前分数、已消除行数、等级、最高分与下一个方块预览。
- **G4**：支持键盘操作（左右移动、旋转、软降、硬降、暂停、重开）。
- **G5**：方块堆叠至顶部时触发游戏结束，并支持一键重新开始。
- **G6**：所有核心玩法均在本地浏览器内运行，无后端依赖。

---

## 3. 非目标（Non-goals）

- 不做多人在线对战或排行榜服务端同步。
- 不做移动端触控 UI 的精细适配（桌面浏览器优先）。
- 不做音效、背景音乐与动画皮肤商城。
- 不做服务端存档或账号系统；本地存档仅存于浏览器 `localStorage`。
- 不依赖任何外部 CDN、前端框架或构建工具。

---

## 4. 用户与使用场景

- **目标用户**：想在浏览器里快速玩一局俄罗斯方块的普通用户。
- **主要场景**：双击打开 `index.html` → 按 Enter 或点击「开始游戏」→ 使用键盘游玩 → 游戏结束后点击「再来一局」。
- **辅助场景**：中途暂停、查看下一块与历史最高分、刷新后恢复未完成对局。

---

## 5. 功能需求（Functional Requirements）

### FR-1 打开即玩
- 页面为纯前端实现，双击 `index.html` 即可在浏览器运行。
- 不依赖外部 CDN、构建步骤或后端服务。

### FR-2 棋盘
- 主游戏区为 **10 列 × 20 行** 网格棋盘。
- 棋盘以 Canvas 渲染，单元格有清晰边框，便于区分格子。

### FR-3 方块
- 支持标准七种方块：I、O、T、S、Z、J、L。
- 每种方块有独立颜色，当前方块与落底预览（ghost）可区分显示。

### FR-4 自动下落
- 方块按固定时间间隔自动向下移动一行。
- 下落间隔随等级提升而缩短（速度加快）。

### FR-5 移动
- 方向键 ← / → 控制方块左右移动，不可越界或穿墙/穿块。

### FR-6 旋转
- ↑ 或 X 键顺时针旋转；Z 键逆时针旋转。
- 旋转时支持简单踢墙（wall kick），靠墙或贴地时仍可尝试旋转。

### FR-7 软降与硬降
- ↓ 键软降：方块向下移动一行，命中底部立即固定。
- 空格键硬降：方块瞬间落到底部，按落距给予加分。

### FR-8 落底固定与新方块
- 方块无法继续下落时固定到棋盘；随后从随机袋生成新方块。
- 使用 7-bag 随机算法，保证七种方块在每袋内各出现一次，分布均匀。

### FR-9 满行消除与计分
- 任意一行被填满时立即消除，上方行整体下移。
- 计分规则：单次消除 1/2/3/4 行分别得 100/300/500/800 分 × 当前等级；硬降每格 2 分；软降每格 1 分。

### FR-10 等级与速度
- 初始等级为 1。
- 每累计消除 10 行等级 +1，下落间隔随等级增加而缩短，最低不低于 80ms。

### FR-11 下一个方块预览
- 右侧面板显示下一个方块，采用与主棋盘一致的颜色。

### FR-12 暂停与继续
- P 键或「暂停」按钮暂停；再次按 P 或「继续」恢复。
- 窗口失焦时自动暂停，避免误操作。

### FR-13 游戏结束与重开
- 新方块生成时即与已有方块重叠（堆至顶部）则游戏结束。
- 游戏结束显示覆盖层，提示本局得分与消除行数，并提供「再来一局」按钮。
- R 键或「重新开始」按钮可在任意时刻重开。

### FR-14 分数与记录持久化
- 最高分、最近对局记录保存在浏览器 `localStorage`。
- 未完成对局状态可保存，刷新页面后可提示恢复。

## 13. 边界与异常

- 方块在生成位置被遮挡 → 判定游戏结束。
- 旋转后越界/重叠 → 依次尝试踢墙偏移，全部失败则放弃旋转。
- 页面失焦 → 运行中自动暂停。
- `localStorage` 不可用或数据损坏 → 忽略持久化错误，使用默认值继续运行。
- 刷新页面存在未完成对局 → 进入暂停态并提示恢复。
