**分支建议：** `feat/a-w3-condition-human`

5. **对接 B**：预留 `agent` 节点调用点（可先 mock 成功路径，接口与 B 对齐）。

**自测命令：**
```bash

# 有 branch-human 样例后：

```

**完成定义：** 单测能证明 condition 选边正确；跑到 human 节点时状态为 `WAITING_USER` 且可被 resume 继续到 DONE。
